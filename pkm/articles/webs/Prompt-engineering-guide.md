# TL;DR

DAIR.AI's open-source guide to prompt engineering: techniques, applications, risks, papers and tools in one site, available in many languages.

# What it does

A structured handbook (also published at promptingguide.ai) with sections for introduction, techniques, applications, a prompt hub by task, per-model pages, risks and misuses, papers, tools, notebooks and datasets, plus a one-hour lecture. Model coverage includes ChatGPT, GPT-4, Gemini, LLaMA, Mistral and Code Llama.

# Key takeaways

1. **Core techniques covered**: zero-shot and few-shot, chain-of-thought, self-consistency, generated knowledge, prompt chaining and Tree of Thoughts.
2. **Agentic and tool-using methods**: ReAct, ART, PAL, Automatic Prompt Engineer and multimodal CoT.
3. **RAG is included** as a prompting technique, with application guides such as function calling and code generation.
4. **Risks section**: adversarial prompting, factuality and biases.
5. **Run it locally** with Node 18+ and pnpm (`pnpm dev`, port 3000).
