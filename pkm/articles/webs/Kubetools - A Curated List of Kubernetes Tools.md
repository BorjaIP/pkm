# TL;DR

A categorised catalogue of 200+ [[Kubernetes]] tools: cluster management, CLI helpers, monitoring, CI/CD, security, service mesh, storage and more.

# What it covers

A single README of headings with entries in the form "tool - description (link)". Some tools appear in several categories. The list is a fork of the Collabnix project and was last updated in February 2021.

# Key takeaways

1. **Cluster and CLI**: kops, kind, Rancher; kubectx/kubens, K9s, kube-shell.
2. **Observability**: Prometheus, Grafana, Thanos, Jaeger, Loki, Fluent Bit, Stern, Chaos Mesh.
3. **Development**: Tilt, Okteto, Garden, ko.
4. **CI/CD**: Argo CD, Flux, Tekton, Spinnaker.
5. **Security and policy**: kube-bench, Kyverno, kube-hunter, Starboard; network policy tools such as Calico.
6. **Mesh and gateways**: Istio, Linkerd, Traefik, Kong.
7. **Storage and ML**: Longhorn, OpenEBS, Rook, Velero; Kubeflow, Volcano.
