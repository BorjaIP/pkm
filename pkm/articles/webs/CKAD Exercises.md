# TL;DR

Practice exercises for the Certified Kubernetes Application Developer exam, organised by exam domain with links to the matching official docs.

# What it does

A set of hands-on exercises by topic, each starting with a breadcrumb that points to the relevant kubernetes.io page, written to be solved with the documentation only (the exam rules). Besides the weighted domains there are sections on Helm, CRDs and podman.

# Key takeaways

1. **Domain weights**: Core Concepts 13%, Multi-container pods 10%, Pod design 20%, Configuration 18%, Observability 18%, Services & networking 13%, State persistence 8%.
2. **Read the docs first**, then try each section's exercises.
3. **Practise doc navigation**: the exam allows only official documentation in a browser inside the exam VM.
4. **Use the extras**: Helm and CRD exercises go beyond the weighted domains.
