# Wiki Catalog

Machine-readable catalog of all pages in the Second Brain. The agent **reads this file first** before answering any question about the wiki. It provides a one-line summary and a direct wikilink for every page, organized by category.

When answering a query:
1. Read this catalog.
2. Identify which rows match the topic (exact + synonyms).
3. Read only those pages (never the entire vault).
4. Synthesize the answer with citations using `[[Page]]` wikilinks.
