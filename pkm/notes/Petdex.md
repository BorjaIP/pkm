**Petdex** ([petdex.dev](https://petdex.dev/)) is a public gallery of animated pets for coding agents, described on its homepage as "the coding agent pet index". You browse thousands of open-source, user-submitted pets, preview their states and install one so it appears on your desktop while the agent works.

## What it offers

- **Gallery:** 5,000+ pets that can be filtered by type, version, color and era, and sorted by most installed. Featured collections are grouped by franchise.
- **Install:** one command, for example `npx petdex install boba`. A desktop app (Petdex Desktop) is also offered.
- **Supported agents:** Claude Code, Codex, Gemini CLI, opencode, Qoder, Kimi Code, CodeBuddy and OMP.
- **Community:** creators leaderboard, requests, a submit page, a "Built with Petdex" section and a Discord.

## Caveats

- Pets are user-submitted fan art. The site says it claims no rights over the underlying IP and has a takedown page.
- The page does not state a license for the platform itself or any pricing, and it does not name the operator directly (it links a GitHub organization, crafter-station).
- `npx petdex install` runs third-party code and assets from the registry; check what a pet does before installing it on a machine with private work.
